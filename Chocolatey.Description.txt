Idle Shutdown automatically powers off inactive Windows computers. It is designed for centrally managed classrooms, laboratories, kiosks and shared workstations where machines should not remain powered on indefinitely.

## Features

- Displays a warning dialog after a configurable period of inactivity in an unlocked user session.
- Cancels the pending shutdown immediately when the user moves the mouse, presses a key or clicks **Continue working**.
- Uses one `IdleMinutes` inactivity timeout for unlocked, locked and no-user states, followed by one shared `WarningSeconds` protection period.
- Detects mouse and keyboard activity on the Windows lock screen and resets the locked-session timer.
- Detects mouse and keyboard activity on the Windows sign-in screen before any user logs on and resets the no-user timer.
- Performs one final lock-screen input check immediately before shutdown to avoid powering off while somebody is entering a password.
- Performs a final no-user state and console-input check immediately before shutdown.
- Runs a hidden input monitor in the physical console session, covering sign-in screens where Windows WTS does not expose LastInputTime.
- Uses `WarningSeconds` as a cancellable final silent warning period for locked/no-user shutdowns; physical input, sign-in or unlock cancels it.
- Uses a non-forced final Windows shutdown request so applications with unsaved work can still block shutdown instead of being terminated automatically.
- Defers every shutdown while Windows reports a system/display power request, Windows Update is actively installing or uninstalling, or an MSI transaction is running.
- Keeps deferred requests pending and checks them again, while new physical input cancels the request.
- Applies a locked-session timeout only when every logged-on session is locked or disconnected; an unlocked session always blocks machine shutdown.
- Runs a separate agent in every local and Remote Desktop user session. Activity or the Continue button in any session cancels shutdown and closes warning dialogs in all sessions.
- Broadcasts one shared warning deadline to every unlocked agent, displays the remaining countdown in each local/RDP session and waits for the latest countdown before shutdown.
- Rejects an expired warning from one idle session while another unlocked user session is still active.
- Protects presentations and media playback by checking Windows system/display power requests, with true-fullscreen foreground-window detection as a fallback.
- Uses a Windows service running as LocalSystem for machine-level monitoring and shutdown, including states where no user is logged on.
- Uses a lightweight per-user agent for interactive idle detection, presentation protection and the warning dialog.
- Automatically localizes the warning dialog for Czech, English, German and Spanish Windows environments, with English as the fallback.
- Automatically follows the Windows light or dark application theme whenever the warning is displayed.
- Shows the running application version unobtrusively in the warning dialog for easier fleet diagnostics.
- Supports safe testing with `DryRun: true`; shutdown decisions are logged without powering off the computer.
- Disables all shutdown actions if the configuration is missing, incomplete or invalid and resumes automatically after it is repaired.
- Writes only important state changes to a shared English-only production log; detailed diagnostics are enabled only in DryRun.
- Rotates the log at 2 MB and retains two archives, limiting total log storage to approximately 6 MB.
- Prevents repeated expired DryRun warning dialogs until new physical input is detected.
- Preserves the existing configuration during Chocolatey upgrades unless `/ResetConfig` is supplied.
- Includes the remote-friendly `idle-shutdown-test` health-check command.

## Installed components

- Windows service: `IdleShutdown`
- Scheduled task: `Idle Shutdown Agent`
- Installation directory: `C:\Program Files\IdleShutdown`
- Configuration: `C:\ProgramData\IdleShutdown\config.json`
- Log: `C:\ProgramData\IdleShutdown\IdleShutdown.log`

## Default configuration

- `IdleMinutes`: `90`
- `WarningSeconds`: `300`
- `CheckIntervalSeconds`: `5`
- `PauseWhenFullscreen`: `true`
- `DryRun`: `false`

With these defaults, every machine state becomes eligible after 90 minutes of inactivity and shuts down after the additional 5-minute warning period. The warning is visible only in unlocked sessions and remains silent on locked/sign-in screens.

## Chocolatey package parameters

- `/IdleMinutes:<minutes>` — inactivity duration for unlocked, locked and no-user states before the protection period starts.
- `/WarningSeconds:<seconds>` — additional protection period before shutdown; displayed as a popup only in unlocked sessions.
- `/CheckIntervalSeconds:<seconds>` — interval used by the service and agent to evaluate the current state.
- `/PauseWhenFullscreen:true|false` — enables or disables presentation and fullscreen protection.
- `/DryRun:true|false` — logs shutdown decisions without powering off the computer when enabled.
- `/ResetConfig` — replaces the existing configuration with package defaults before applying other parameters.

## Examples

Installation with production defaults:

```powershell
choco install idle-shutdown -y
```

Short safe test:

```powershell
choco install idle-shutdown -y --params="'/IdleMinutes:1 /WarningSeconds:30 /CheckIntervalSeconds:5 /PauseWhenFullscreen:false /DryRun:true'"
```

Upgrade while changing selected values:

```powershell
choco upgrade idle-shutdown -y --params="'/IdleMinutes:30 /WarningSeconds:60'"
```

Health check:

```powershell
idle-shutdown-test
```
